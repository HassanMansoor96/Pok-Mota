# PokéMota

A premium South African Pokémon TCG storefront. Planned visual identity: obsidian black, gold, and emerald green.

## Project goals
- Mobile-first storefront for individual cards and sealed Pokémon TCG products.
- Search and filtering by Pokémon, set, rarity, condition, and price (ZAR).
- Basket and secure South African checkout; Payfast and courier options require production accounts and verification before launch.
- Private admin dashboard with bulk CSV import, stock tracking, card photos, and order management.

## Delivery stages
1. Interactive storefront prototype in vanilla HTML, CSS, and JavaScript.
2. Node.js/Express API and PostgreSQL inventory/order system.
3. Payment and shipping integrations, security, testing, and deployment.

The initial prototype uses example inventory only. No payment handling or production customer data is enabled until backend and integrations are complete.
